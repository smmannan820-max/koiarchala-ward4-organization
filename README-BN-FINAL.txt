এই প্যাকেজে রয়েছে:
- index.html — সংগঠনের প্রকাশ্য ওয়েবসাইট
- admin.html — অ্যাডমিন প্যানেল
- app.js, admin.js — ওয়েবসাইট ও অ্যাডমিনের কার্যক্রম
- styles.css — মোবাইল/কম্পিউটার উপযোগী ডিজাইন
- assets/logo.jpg — সংগঠনের লোগো
- firestore.rules — প্রস্তাবিত Firestore নিরাপত্তা নিয়ম (প্রকাশের আগে বর্তমান নিয়মের সঙ্গে মিলিয়ে দেখুন)

গুরুত্বপূর্ণ: আপনার GitHub রিপোজিটরির firebase-config.js ফাইলটি অবশ্যই আগের মতো রাখবেন। এটি ZIP-এ নেই। আপনার Firebase-এর আগের সদস্য/তথ্য Firestore-এ থাকে; এই প্যাকেজ সেগুলো মুছে না।

GitHub-এ মোবাইল থেকে আপডেট:
১) https://github.com/smmannan820-max/koiarchala-ward4-organization খুলে সাইন ইন করুন।
২) রিপোজিটরির মূল পাতায় Add file > Upload files চাপুন। ZIP ফাইলটি আগে ফোনে Extract/Unzip করুন; ZIP-টি সরাসরি রিপোজিটরিতে আপলোড করবেন না।
৩) index.html, admin.html, app.js, admin.js, styles.css ফাইলগুলো মূল ফোল্ডারে আপলোড করে আগের একই নামের ফাইল Replace করুন।
৪) assets ফোল্ডারের ভেতরে logo.jpg আপলোড করুন।
৫) firebase-config.js মুছবেন/বদলাবেন না।
৬) Commit changes চাপুন। GitHub Pages আপডেট হতে কয়েক মিনিট লাগতে পারে।

Firestore:
- অ্যাডমিন অনুমতি admins/{আপনার UID} নথি থেকে যাচাই হয়।

- আগের ডেটা মুছে ফেলার কোনো নির্দেশ এই প্যাকেজে নেই।

গুরুত্বপূর্ণ সীমাবদ্ধতা ও যাচাই:
- এই প্যাকেজের JavaScript syntax পরীক্ষা করা হয়েছে এবং ZIP আর্কাইভ পরীক্ষা করা হয়েছে। কিন্তু আপনার লাইভ Firebase-এ লগইন করে বাস্তব ডেটা লেখা/পড়া পরীক্ষা করা হয়নি। তাই GitHub-এ আপলোডের পর অ্যাডমিন লগইন, একটি পরীক্ষামূলক রেকর্ড যোগ/মুছে ফেলা এবং প্রকাশ্য সাইটে দেখা যাচাই করুন।
- সদস্য নম্বর KWO-001 ইত্যাদি বর্তমান সদস্যসংখ্যা ধরে তৈরি হয়; একসঙ্গে একাধিক অ্যাডমিন সদস্য যোগ করলে নম্বর সংঘর্ষ হতে পারে।
- প্রকাশ্য সদস্য তালিকায় মোবাইল/ঠিকানা দেখানোর আগে সংশ্লিষ্ট সদস্যদের সম্মতি নিন।
- তালিকার সম্পাদনা বাটনে ফিল্ড ধরে prompt আসবে। ছবি বদলাতে হলে রেকর্ড মুছে নতুন ছবি দিয়ে আবার যোগ করতে হবে।
