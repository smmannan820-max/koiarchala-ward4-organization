# কৈয়ারচালা ৪নং ওয়ার্ড উন্নয়ন সংগঠন
এই ZIP একটি প্রাথমিক ওয়েবসাইট স্টার্টার। এটি এখনো লাইভ নয় এবং বাস্তব পরিবেশে পরীক্ষা করা হয়নি।

ফাইল: index.html (সাইট), admin.html (অ্যাডমিন), app.js/admin.js (কোড), firebase-config.js (কনফিগ), firestore.rules (নিরাপত্তা নিয়ম)।

Firebase project: koiarchala-ward-4-organization
Cloudinary cloud: ey1okwcq; unsigned preset: koiarchala_members

প্রকাশের আগে Firestore Rules পর্যালোচনা ও প্রয়োগ, অ্যাডমিন Authentication account যাচাই, ফর্ম ও Cloudinary upload পরীক্ষা এবং Hosting deploy করতে হবে। পুরোনো Firestore Rules-এর ব্যাকআপ না নিয়ে বদলাবেন না। Firebase password, OTP বা API Secret কখনো শেয়ার করবেন না।
